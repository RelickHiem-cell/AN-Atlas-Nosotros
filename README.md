# Atlas Virtual 3D — Serie de Informes Técnicos de la OMS

Atlas interactivo en 3D que visualiza indicadores de salud de la **Organización Mundial de la Salud (OMS)** relacionados con la **Serie de Informes Técnicos (WHO Technical Report Series - TRS)**.

## Características

- Globo 3D interactivo (Three.js)
- 4 categorías de indicadores basados en datos reales del Global Health Observatory
- Marcadores por país con código de colores
- Panel de información con valores y **enlaces a informes TRS reales**
- Completamente en español
- Interfaz moderna y responsive

## Categorías disponibles

| Categoría | Indicador principal |
|-----------|---------------------|
| Vacunas y biológicos | Cobertura de vacunación DTP3 (%) |
| Preparaciones farmacéuticas | Acceso / calidad de medicamentos |
| Cobertura sanitaria universal | Índice UHC |
| Mortalidad infantil | Mortalidad de menores de 5 años (por 1000) |

## Cómo usarlo

1. Abre el enlace de GitHub Pages
2. Arrastra el globo para rotar
3. Usa la rueda del ratón para hacer zoom
4. Haz clic en cualquier marcador de color para ver los datos del país y los informes TRS relacionados

## Tecnologías

- HTML5 + CSS3
- Three.js (WebGL)
- Datos basados en WHO Global Health Observatory y World Health Statistics
